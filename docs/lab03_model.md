## Структура part-of

```
Теплиця
├── Відсік_теплиці
│   ├── Кватирка
│   ├── Система_обігріву
│   ├── Затінювальний_екран
│   ├── Циркуляційний_вентилятор
│   ├── Система_зволоження
│   ├── Система_досвітлення
│   └── Датчик
├── Генератор_CO2
├── Кліматичний_контролер
└── Метеостанція

Томат
├── Лист
├── Квітка
└── Плід
```

## Перевірка ребер is-a

| Твердження | Результат | Рішення |
|---|---|---|
| Кожна кватирка є виконавчим механізмом | істинне | is-a |
| Кожен критичний перегрів є перегрівом | істинне | is-a (3-й рівень станів) |
| Кожна сіра гниль є хворобою | істинне | is-a |
| Кожен томат є рослиною | істинне | is-a |
| Кожен відсік є теплицею | хибне | part-of: Відсік_теплиці part-of Теплиця |
| Кожна кватирка є відсіком | хибне | part-of: Кватирка part-of Відсік_теплиці |
| Кожна квітка є томатом | хибне | part-of: Квітка part-of Томат |
| Кожен датчик є кліматичним контролером | хибне | відношення передає_дані |
| Кожне провітрювання є кватиркою | хибне | відношення виконує (Кватирка виконує Провітрювання) |
| Кожен конденсат на листі є сірою гниллю | хибне | відношення спричиняє |

## Предметні відношення

| Відношення | Домен | Діапазон | Приклад |
|---|---|---|---|
| вимірює | Вимірювальний_пристрій | Параметр | Датчик вимірює Температура_повітря |
| передає_дані | Вимірювальний_пристрій | Кліматичний_контролер | Датчик передає_дані Кліматичний_контролер |
| керує | Кліматичний_контролер | Виконавчий_механізм | Кліматичний_контролер керує Кватирка |
| зберігає | Кліматичний_контролер | Параметр | Кліматичний_контролер зберігає Уставка_температури |
| виконує | Виконавчий_механізм | Керуюча_дія | Кватирка виконує Провітрювання |
| змінює | Дія | Параметр | Провітрювання змінює Відносна_вологість |
| усуває | Дія | Стан | Обігрів усуває Переохолодження |
| посилює | Дія | Стан | Випарне_охолодження посилює Надмірна_вологість |
| запобігає | Дія | Причина | Плавне_підвищення_уставки запобігає Різке_підвищення_температури |
| несумісна_з | Дія | Дія | Подача_CO2 несумісна_з Провітрювання |
| визначається_за | Відхилення_мікроклімату | Параметр | Перегрів визначається_за Температура_повітря |
| спричиняє | Стан ∪ Причина | Симптом ∪ Причина | Надмірна_вологість спричиняє Сіра_гниль |
| проявляється_на | Симптом | Лист ∪ Квітка ∪ Плід | Мікротріщини_плодів проявляється_на Плід |
| уражає | Хвороба | Лист ∪ Квітка ∪ Плід | Сіра_гниль уражає Лист |
| вирощується_в | Рослина | Відсік_теплиці | Томат вирощується_в Відсік_теплиці |
| має_фазу | Рослина | Фаза_розвитку | Томат має_фазу Фаза_розвитку |

## Винятки

| № | Виняток | Спосіб | Чому саме так |
|---|---|---|---|
| V1 | Дії, що знижують температуру, усувають Перегрів, ОКРІМ Випарного_охолодження у спекотний вологий день: воно посилює Надмірну_вологість (E1). | Пріоритет правил | Виняток описується конкретним правилом (умова: висока Зовнішня_вологість), яке перекриває загальне. |
| V2 | Провітрювання усуває Надмірну_вологість (R6), ОКРІМ холодної погоди: тоді Цикл_нагріву_й_провітрювання або Циркуляція_повітря (R7, E3). | Пріоритет правил | Специфічніше правило R7 (вологість І холодно) перекриває загальне R6. |
| V3 | Керуючі дії за замовчуванням виконуються одразу, ОКРІМ Обігріву: температуру підвищують плавно, не швидше 2 °C/год (E4). | Значення за замовчуванням | Виняток один і заздалегідь відомий: властивість «швидкість зміни» перевизначається для класу Обігрів. |
| V4 | Подача_CO2 усуває Дефіцит_CO2, але висновок «подавати» скасовується, щойно надходить факт «кватирки відкрито» або «настала ніч» (R10, R11, M1). | Немонотонна логіка | Виняток з’являється під час роботи: новий факт скасовує вже зроблений висновок. |
| V5 | Перегрів спричиняє Погане_запилення не завжди: це залежить від тривалості перегріву й вологості. | Ймовірнісний перехід | Винятків багато, а статистику можна отримати з даних AGC (ЛР 11). |

## Аналіз графа

- Ізольовані вершини: Час_доби (перенесено в атрибути контексту), Ранковий_полив (поза межами задачі, вилучити).
- Щільні вузли: Виконавчий_механізм, Відсік_теплиці (структурні), Провітрювання (подвійне призначення, M2).
- Розриви: немає; Система_досвітлення, Критичний_перегрів, Критичне_переохолодження мають лише структурні зв'язки — прогалина для ЛР 4.
